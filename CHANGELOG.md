# Changelog

Notable project changes are documented here. The repository was prepared for public open-source development from an existing working source snapshot, so earlier private development history is not reconstructed or invented.

## Unreleased

- Removed maintainer-specific cloud project configuration from public source.
- Added ADC/environment-based Vertex project discovery.
- Added public security, privacy, architecture, contribution, and roadmap documentation.
- Added GitHub issue/PR templates and Windows CI configuration.
- Removed local virtual environments, build outputs, caches, backups, logs, and private development artifacts from the public tree.
- Switched the public source bundle to installed system-font fallback instead of redistributing a font binary.

## 1.3.0

Current application source snapshot, including local/cloud Georgian STT, optional Vertex AI transcript processing, secure Deepgram credential storage, diagnostics, global hotkeys, Windows text insertion, and a focus-safe overlay.
