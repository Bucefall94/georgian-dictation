# Code of Conduct

Georgian Dictation welcomes technical collaboration from people with different backgrounds and levels of experience.

Be respectful, discuss code and behavior rather than people, avoid harassment or discriminatory language, and do not publish another person's private information. Maintainers may remove abusive, unsafe, spammy, or off-topic contributions and may restrict participation when necessary to keep the project usable and constructive.

Security reports and sensitive user data should never be posted publicly; follow [SECURITY.md](SECURITY.md).
